Features
- Live Visitors: Real-time count with 15s auto-refresh
- Live Clicks: Click tracking with element selectors
- Heatmap: Canvas-based click heatmap overlay with device/page filters
- Session Replay: rrweb-powered recording with privacy masking
- UTM: Source/medium/campaign attribution with bar charts
- Conversion: Goal tracking with doughnut charts
Activation
1. Activate the plugin in WordPress admin
2. Database tables auto-create on activation
3. Go to Simple Analytics in the sidebar
4. Enable session recording in Settings if desired
